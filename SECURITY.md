# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential, privacy problem, or authorization bypass.

Email [support@gethands.nl](mailto:support@gethands.nl) with **security** in the subject. Include the affected surface, impact, safe reproduction steps, and a way to contact you. Do not send live secrets; redact tokens, personal data, tenant content, and private source.

The Hands team reads support mail on weekdays, 09:00–17:00 Europe/Amsterdam. We will acknowledge and triage reports according to severity; this preview does not promise a fixed bounty or resolution time.

## Supported versions

There is no public SDK release yet. Documentation-preview content does not constitute a supported software version. Supported versions, update policy, and disclosure process will be added with the first source release.

## Boundary reminder

Local validation, discovery, or provider conformance never grants production execution authority. Please report any behavior that appears to cross tenant, credential, recipient, spending, locality, action-scope, or approval boundaries.
