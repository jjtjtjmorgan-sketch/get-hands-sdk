Status words have precise meanings throughout these pages:

| Word | Meaning |
| --- | --- |
| Demonstrated prototype | Observed in the private development environment; not necessarily published or supported |
| Developer Preview | Public artifact exists, but its interface or support promise may change |
| Shipped | Versioned public artifact and matching evidence exist |
| Planned | Intended direction; not currently available |

If a page does not provide a public artifact or reproducible path, do not infer availability from a roadmap statement.
